MSB groups its attacks into four surfaces, each hitting a different hop of that pipeline. Tool signature: a lookalike tool name, or instructions hidden inside a tool's description. Tool parameter: a tool whose inputs ask for something it has no business knowing, like the name of the model calling it. Tool response: the real reply is thrown away and replaced with a fake error, or a fake message pretending to come from the user. And retrieval injection: instructions hidden inside a document the agent was asked to read. Notice the card on the left. The user is innocent in every scenario. These attacks hijack completely honest requests.
