Conclusion

What this project actually proves

MCP-SecBench provides a benchmark-integrated defensive middleware for MCP-based LLM agents. It evaluates whether tool-signature validation, parameter gating, and tool-response sanitization can reduce attack success against MCP security threats, comparing undefended and defended agents under identical conditions.

We showed

All 12 MSB attack types execute end to end. The guard measurably intercepts real MSB attack payloads — verified live, with no API key, against real source code.

We did not show

General MCP security, protection against unseen or paraphrased attacks, or a statistically validated ASR reduction on a model actually vulnerable to these attacks.

github.com/KavyaSharma1806/MCP-SecBench

The system provides a prototype middleware defense against selected MCP attack classes. It is not claimed to solve MCP security or to detect all prompt injection. That distinction is the whole point of presenting it this way.
