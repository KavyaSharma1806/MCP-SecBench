MCP Security

MCP-SecBench

Security benchmarking and defensive middleware for MCP-based LLM agents

Built on MCP Security Bench (MSB) · ICLR 2026

October 2026

Welcome. This talk is about a new kind of security problem that appears the moment you let an AI model take actions in the real world, and about a practical attempt to defend against it. Here's the plan. First, I'll build up the background from scratch: what an AI "tool" actually is, how the Model Context Protocol connects models to tools, and exactly where an attacker can get in. Second, I'll explain MCP Security Bench, or MSB, a published research benchmark that measures these attacks, and walk through how its benchmarking actually works, step by step, because the details matter. Third, I'll show what we added on top of MSB, which I'll call our delta, and I'll be strict about separating what MSB already does from what is genuinely new. Fourth, the results, measured on real local models, including some honest surprises and one bug in our own scoring that we found and fixed while preparing this. And finally, the limitations, because a security prototype that can't state its own limits isn't trustworthy.
