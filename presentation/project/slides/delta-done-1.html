Rule we followed: if MSB already does it, it is not our contribution.

So what exactly is our delta, meaning what exists here that is not in MSB? We hold ourselves to a strict rule: if MSB already does it, it doesn't count as ours, even if we re-implemented it. Part one is the defense and the experiment. Defense: MSB has no defense code at all. We built mcp_guard, with three checks and a security policy, which turns MSB's measurement into a mitigation you can actually test. Integration: the guard attaches to MSB's agent at runtime, without editing a line of MSB, so the baseline is exactly MSB and the comparison is fair. Experiment: MSB only ever runs undefended agents. We run every scenario twice, with and without the guard, which isolates the guard's effect. Metrics: on top of MSB's three, we added mitigation rate and per-component intervention counts, so we can show the guard acted rather than the attack failing by chance.
