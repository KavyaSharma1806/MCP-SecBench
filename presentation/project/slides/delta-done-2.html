Part two of our delta: measurement and tooling. Judging: MSB parses its logs after the run and, for three goals, only checks that a file exists. Our judge runs in-process, checks the file's content, and has a proper oracle for parameter leaks. So a file with harmless text no longer counts as a success. Evidence and validity: we save every tool call for every scenario, and check that each run actually executed tools. That check is what exposed the meaningless zeros under MSB's prompt. Prompt setting: the native tool-call setting, always reported next to MSB's, is what made the 8B results meaningful. And coverage and tooling: the twelve-type executability check, the three-mode CLI, the live demo and the local models mean anyone can rerun all of this offline, at zero cost.
