mcp_guard.py

Three components, one proxy

SecurityGuard

apply_defense(agent)

Tool Signature Validation

Drops exact duplicate tool names. Strips known injection markers out of tool descriptions before they reach the system prompt.

catches: <INFORMATION>, <IMPORTANT>, exact name collisions

Parameter Gating

Refuses tool calls carrying out-of-scope keys, secret-like keys, or high-risk payloads before dispatch.

catches: llm_model_name, api_key, ssh-rsa content

Response Sanitization

Scans tool observations for MSB's canned attack templates and redacts them before the LLM reads them.

catches: fake "Error", fake "new user query"

Signature validation and the system-prompt policy run once at agent setup. Parameter gating runs before every tool call; response sanitization runs after every tool call, including MSB's own canned attack-response substitutions. This is a per-instance monkey-patch of the agent executor's tool-dispatch method -- not an edit to mcp_use or langchain source.
