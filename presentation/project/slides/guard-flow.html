This is what happens on each tool call, from top to bottom. The agent decides on a call. check_parameters looks at the arguments. If something is wrong, the call is refused and nothing is sent anywhere; the agent gets a refusal message it can read and recover from. That's the orange branch. Otherwise, MSB's original dispatch runs completely unchanged. That means either the real tool runs, or MSB substitutes its attack reply exactly as it would in a baseline run, so we never weaken the attack. Whatever comes back then passes through sanitize_response before the agent sees it. On the right is how we attach without editing MSB: re-check the tool list, rebuild the system prompt with a policy, and wrap the one method that executes tool calls, on this one agent object only. Baseline runs never see the change.
