This is the honest story of the project, phase by phase. Click through one row at a time. Setup: MSB assumes Linux and paid model APIs. We had neither, so we built a Windows-safe setup and switched to free local models through Ollama. Build: we wrote the guard and the command-line runner. Early on, results from different models overwrote each other, so we keyed every result row by model. First results: we measured the 3B model and added the 8B. At that point we read the 8B model's zeros as a real result. We later withdrew that claim. Audit: we checked all twelve attack types and built the coverage matrix, and found we had wrongly marked prompt injection as defended. Judge fix: our parameter-attack judge was looking for a file that attack never writes, so it could never record a success. Fixing it revealed the real 3B result: thirty-six percent down to zero. Validity: the 8B model wasn't running tools at all under MSB's prompt. Finding out why gave us the native setting, and one hundred percent down to zero. Every correction made the results more trustworthy, not less.
