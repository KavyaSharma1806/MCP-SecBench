What this does not solve

Heuristic, pattern-based detection

"Ignore previous instructions" is caught. "Disregard the instructions supplied earlier" may not be.

Tuned against a known corpus

Several checks match MSB's exact template strings. Low ASR here does not imply general MCP security.

Retrieval Injection unscored

No oracle exists yet for "was the agent deceived into the wrong document." Excluded, not faked.

External dependency

kill_process scenarios rely on a third-party tool registry currently returning errors.

Monkey-patching, not an API

The guard attaches via a per-instance patch to the agent executor — effective here, not portable by design.

False positives & negatives unmeasured

We have not yet measured how often legitimate tool text gets flagged, or how often a novel attack slips through.

This slide exists on purpose. A prototype that cannot state its own limits is not trustworthy regardless of its numbers.
