02 · How attacks are measured

MSB measures attacks, end to end

A published benchmark (ICLR 2026). It gives a real LLM agent real MCP tools and an everyday task, secretly injects an attack, then checks whether the harm actually happened.

It ships the attacks, tasks, judge and metrics: a repeatable instrument.

What MSB does not have

A defense. Its repository measures attacks; it contains no defensive code.

MCP Security Bench is a benchmark published at ICLR 2026. It turns these attacks from anecdotes into measurements. It sets up a real agent with real tools, gives it an everyday task, secretly injects an attack, and then checks whether the harm actually happened. The four numbers are MSB's own, from its repository: twelve attack types across the four surfaces, more than two thousand attack instances, ten LLM agents evaluated, and an average attack success rate of forty point three five percent. And the box on the left is our opening. MSB measures the problem very well, but its repository contains no defense at all.
