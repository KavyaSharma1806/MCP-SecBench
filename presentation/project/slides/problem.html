Agents now act through third-party tools

Every tool talks to the model in plain text: its name, its description, its replies.

If an attacker writes that text, it can steer the agent: leak data, plant a login key, kill a process.

Source: MCP Security Bench repository README

Here's why this matters. AI agents don't just chat any more. They search the web, read files and run commands, all through tools. A tool talks to the model entirely in text: its name, its description, and its replies. Someone else wrote that text. If that someone is an attacker, the text can steer the agent into doing harm. That isn't hypothetical. Across ten LLM agents and twelve attack types, the MSB benchmark measured an average attack success rate of about forty percent.
