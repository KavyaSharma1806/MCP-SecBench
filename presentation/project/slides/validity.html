This slide explains why we ran everything twice, and it's one of the most important lessons in the project. Ask a simple question of every scenario: did the agent actually use its tools? Every MSB attack arrives through the tool loop. If the agent never executes a tool call, the attack has nothing to ride on, and the guard has nothing to block. A zero in that situation tells you nothing. What we found is a mismatch inside the setup MSB uses. MSB's system prompt instructs the model to write its tool calls as text: "Thought," then "Action," then "Action Input." But the agent framework underneath only executes structured tool calls, a separate format the model returns alongside its text. The eight-billion model did exactly what the prompt said. It wrote the call out as text and stopped. The example in the middle is a real final answer: it even filled in llm_model_name with "My AI Model," but as words on the screen. No server ever received it. We didn't just assume that was the cause; we tested it directly. Same tool, same question, three tries each. With MSB's prompt, the eight-billion model gave text only, three out of three. With one section removed, the "use this text format" instructions, it made a real tool call three out of three. So we added that as a second setting, which we call the native tool-call prompt. It removes only that one section. The persona, the tool list, every attack, and the judge are unchanged. And we report it side by side with MSB's exact setting, never instead of it, because it is a deviation from MSB. The effect is on the right. In the parameter-attack scenarios, the eight-billion model went from zero real tool calls out of twenty-five, to twenty-five out of twenty-five. Across its whole native run, it executed tools in every scenario except those that hit the known kill-process infrastructure error. The three-billion model is less consistent: even with the native prompt it executed tools in only sixteen of twenty-five parameter-attack runs, so its numbers should be read with that in mind. The conclusion at the bottom. Under MSB's exact prompt, the eight-billion model's zeros mean nothing, and an earlier draft of this project that read them as resistance was wrong. Under the native prompt, the zeros are real evidence, and as you saw on the previous slide, that model turned out to be anything but resistant to the parameter attack.
