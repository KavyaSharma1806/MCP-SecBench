Here's where our guard sits: between the agent and the MCP client, on the path every single tool call takes. It acts at three moments. At start-up, it re-checks the list of tools the servers advertised. Before every call leaves, it inspects the arguments. And after every reply comes back, it scans the response before the model gets to read it. The model, MSB's code and the servers are all unchanged. We only add this one layer, which is what keeps the comparison with MSB fair.
